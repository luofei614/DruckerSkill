# 知识分析画布 · 字段定义（Schema）

> 配合 `assets/knowledge_canvas_template.html`。画布 = 三源列 × 结论行，每格四字段。
> 下游 `ddd-knowledge-manual` 的手册 v1 可直接消费本画布的独特知识清单。

## 一、画布结构（三源列）

| 列 | 对应 | 行 |
|---|---|---|
| ① 跟别人比（Who vs Others） | kp-07-04·A | 1.1 干得好别人干不了（独特知识候选） / 1.2 干不好别人能干成（知识短板） |
| ② 跟自己比（Self Compare） | kp-07-04·B | 2.1 成败绩效解释（成功因素） / 2.2 成败绩效解释（失败教训） |
| ③ 问优秀顾客（Best Customers） | kp-07-04·C | 3.1 别人做不到的事（顾客视角的独特价值） |

> 注：①.2「知识短板」= 知识侧对顾客侧「非顾客」的对称反转——别人干得了我们干不了，是知识缺口。

## 二、每格四字段

| 字段 | 含义 | 填写规则 |
|---|---|---|
| **结论** | 升维后的判断 | 一句可执行陈述；动词+名词（独特知识类） |
| **原话支撑** | 溯源原话 | 「原话文本」（来源·题号·时间戳）；无原话填「证据不足·建议补访」 |
| **置信度** | 高/中/低 | 高=多源一致；中=部分；低=单条/矛盾 |
| **状态** | verified / hypothesis / insufficient | 已验证 / 假设·待验证 / 证据不足·建议补访 |

## 四、填写自检清单
- [ ] 三源列齐全（A/B/C 都处理）？
- [ ] A 类含双向（独特 + 短板）？
- [ ] 每格有 ≥1 原话？无则标 insufficient？
- [ ] 独特知识均为动词+名词？无形容词伪知识？
- [ ] 资源项已标 R 且未混入知识清单？
- [ ] 四维度诊断含魔鬼代言人？
- [ ] 报告含易腐提示（半年回顾）？
- [ ] 五维交汇卡标「草稿·假设·待验证」？

## 五、与 ddd-knowledge-survey 衔接
- 上游 `knowledge_canvas_frame.md`（填充版）的「跟别人比/跟自己比/问优秀顾客 → 结论」直接映射到本画布三列。
- 上游 `diagnosis_schema.md` 的「诊断1/2/3/4」对应本画布四维度（对/值/深/新）。
- 本画布产出的 K 系列独特知识，可直接作为 `ddd-knowledge-manual` 手册 v1 的「独特知识清单」种子。
