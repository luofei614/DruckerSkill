# 知识洞察分析 Playbook（7 步流水线展开）

> 配合 SKILL.md 的总流程。每一步给：目标 / 操作 / 输出 / 锚定 KP / 常见错误。

## ① 立场校准（成果锚定）
- **目标**：明确本次知识分析服务的成果/行动，避免自嗨式盘点。
- **操作**：回填一句话——「本次知识分析用于 ______（盘点独特知识 / 诊断知识健康度 / 找事业新机会），服务于 ______（具体成果/外部差异化）」。
- **输出**：成果锚定句（写入画布/报告头部）。
- **KP**：kp-07-01（知识即企业→差异化根源）、kp-01-01（成果在外部）。
- **常见错误**：直接开列「我们有哪些知识」却不锚定成果，导致知识清单无取舍标准。

## ② 三源重建（跟别人比 / 跟自己比 / 问优秀顾客）
- **目标**：把杂乱原话归位到 A/B/C 三源，结构对齐德鲁克三问。
- **操作**：
  - **A 跟别人比**：拆双向——A1「干得好别人干不了」、A2「干不好别人能干成（知识短板）」。
  - **B 跟自己比**：成败对照——同一业务成功 vs 失败，解释绩效差异（锚定具体项目/渠道）。
  - **C 问优秀顾客**：提取「别人做不到的事」（可对接 `ddd-customer-survey` 的 D1 数据，避免重复探询）。
- **输出**：三源分列的原话矩阵。
- **KP**：kp-07-04。
- **常见错误**：只做 A1 忽略 A2（知识短板）；B 类只列成功不列失败，失去诊断价值。

## ③ 资源 vs 知识甄别
- **目标**：逐条判断 R(资源)/K(知识)，防止把可购买优势当独特知识。
- **操作**：对②每条原话打标：
  - **R 资源**：渠道关系、厂房设备、资金、政策红利、品牌流量——可购买/可替代，不计入知识。
  - **K 知识**：某人/某团队把信息做成成果的能力，难复制。
- **输出**：R/K 标注矩阵。
- **KP**：kp-07-02（信息≠知识）、kp-07-03（独特知识）。
- **常见错误**：把「我们渠道广」「我们有大厂房」列为知识。

## ④ 动词+名词提炼
- **目标**：把 K 类候选抽象为德鲁克标准表达。
- **操作**：改写为「在 ______ 领域，能做好 ______ 事」（动词+名词）。例：「B站霸榜的高质量视频课」→「在 B站知识区，能持续产出霸榜的高质量视频课」。
- **输出**：动词+名词独特知识候选清单。
- **KP**：kp-07-08（知识的表达·具体而非笼统）。
- **常见错误**：保留「我们质量好」「服务优」等形容词伪知识；或写成名词短语缺动词。

## ⑤ 四维度诊断（对 / 值 / 深 / 新）
- **目标**：对每条独特知识做健康度体检。
- **操作**：逐条答四问 + 魔鬼代言人：
  - **对（正确）**：指向领先？有顾客证据？
  - **值（回报）**：收入真来自这？还是来自渠道/资源？
  - **深（融入）**：系统化嵌入交付？还是只在几个人脑子里（关键人风险）？
  - **新（改进）**：过时风险？哪些场景在浪费这条知识（未充分用）？
  - **魔鬼代言人**：每维度写 3 条尖锐质疑（「凭什么说顾客真为这付费？」「人走了知识还在吗？」）。
- **输出**：四维度诊断表（每知识一行，四维度评级 + 质疑 + 薄弱项）。
- **KP**：kp-07-07（知识诊断四维度）。
- **常见错误**：只评「对」不评「深/新」；无魔鬼代言人，结论过于乐观。

## ⑥ 五维交汇（轻量草稿）
- **目标**：用五维交汇产出事业新机会假设卡（草稿，不展开知识库）。
- **操作**：取五维填表——
  1. 顾客三问（来自 customer-insight / D1）
  2. 独特知识（④产出）
  3. 企业渴望（用户补充）
  4. 外界变化（用户补充）
  5. 未满足需求（用户补充）
  → 交汇出 1–3 张「事业新机会假设卡」，每张标「草稿·假设·待验证」。
- **输出**：事业新机会假设卡（含来源维度标注）。
- **KP**：kp-07-09（双向反馈）、kp-07-10（重新定义）、kp-07-11（差异化四策）。
- **常见错误**：把假设当结论；五维只填了 2–3 维就下判断。

## ⑦ HTML 画布 + 报告组装
- **目标**：用模板产出可交付物。
- **操作**：用 `assets/knowledge_canvas_template.html` 填画布（三源列×结论，每格 结论/原话支撑/置信度/状态）；用 `assets/insight_report_template.html` 填报告（动词+名词清单 / 四维度诊断 / 五维机会卡）。每格挂原话+置信度。
- **输出**：两份 HTML（打印友好、可导出 PDF）。
- **常见错误**：画布格无原话；置信度全填「高」；报告缺易腐提示。

## 认知偏差自检模板（kp-07-05 五项原则对照）
| 原则 | 自检问题 | 触发红旗 |
|---|---|---|
| 看似简单实则困难 | 这条知识真那么容易保持领先吗？ | 把浅显能力当独特 |
| 需要多加练习 | 它靠持续练习维持吗？ | 以为天然具备 |
| 易腐商品 | 它多久会过时？标了 perishability 吗？ | 无保鲜意识 |
| 终将过时 | 哪些信号说明它已过时？ | 从不质疑 |
| 专注卓越 | 我们在它上面专注卓越了吗？ | 广撒网无重点 |

## 置信度约定
- **高**：多源一致（A+B+C 互证）或优秀顾客原话明确。
- **中**：部分提及 / 单一源。
- **低**：单条或矛盾 / 推断无原话 → 标「证据不足·建议补访」。
