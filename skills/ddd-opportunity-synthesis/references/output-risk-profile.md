# 机会综合产物 · 输出风险画像（Output Risk Profile）

> 综合产物最常犯的 6 类错误与 reviewer 检查项。synthesis 比单一分析更靠近"战略结论"，故纯净度与"不替结论"要求更严。

## 一、8 类错误
1. **措辞漂移**：把 kp-07-09 的"错失或低估"写成"错过/漏掉"——破坏理论准确性。
2. **无原话支撑**：机会/能力条目无 src 溯源，变成 AI 凭空发挥。
3. **替企业拍板**：把"假设·待验证"的机会写成既定战略结论。
4. **纯净度泄漏**：HTML 交付物残留 `kp-` / 德鲁克 / 方法论 等内部痕迹。
5. **重复上游**：重算顾客/知识分析而非消费 bundle，导致口径冲突。
6. **创新源空泛**：只说"有创新机会"却不标具体 KP（尤其漏标 kp-i09-01）。
7. **外部信息编造/无出处**：标 `市场公开信息` 的条目无 source（URL/报告名），或凭空写行业份额/趋势——违反市场情报诚信红线。
8. **来源类型未分层**：机会/能力未打 `企业原话`/`市场公开信息`/`AI推演`，或外部条目伪装成企业原话——破坏数据信任分层。

## 二、reviewer 检查项（门禁前自检）
- [ ] 所有"错失或低估"措辞确为 kp-07-09 原样（非"错过"）？
- [ ] 每条机会/能力 ≥1 溯源（企业原话 src 或 市场出处）？无则标"证据不足/外部情报缺失"？
- [ ] 双向反馈/三向交汇是否全标"草稿·假设·待验证"？
- [ ] HTML 字符串扫描零 `kp-`/德鲁克/方法论？
- [ ] 是否消费而非重算上游（双 bundle 字段对齐）？
- [ ] ⑥ 每条机会是否标注具体创新源 KP（新知识源必标 kp-i09-01）？
- [ ] Word 版 [内部]方法论说明已真实生成（非仅改后缀）？
- [ ] 矩阵单元格是否填"是否需该能力 + 支撑强度"而非留空？
- [ ] 标 `市场公开信息` 的条目是否都有出处（URL/报告名），且无凭空行业数字？
- [ ] 每条机会/能力是否打了来源类型（企业原话/市场公开信息/AI推演），外部条目未伪装成企业原话？
- [ ] 未提供且无检索时是否显式标注「未引入外部市场情报」而非编造外部结论？
