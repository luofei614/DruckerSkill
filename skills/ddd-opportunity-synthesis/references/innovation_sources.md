# 德鲁克 7 大创新源（Innovation Sources）

> 配合 `SKILL.md` 总流程 ⑥ 与 `references/drucker_kb_precompiled.md` 的 kp-i 系列。用于对新机会清单逐条做"创新源归因"。四源在机构/产业内部，三源在外部，按可靠性排序（外部变化类更可被主动寻找）。

## 一、七个来源（含特征词 · 供归因匹配）

### 1. 意外（kp-i03-01 · 内部）
- 意外的成功 / 意外的失败 / 意外的外部事件。
- 特征词：没想到成了、本想做A却成了B、行业外事件倒逼。
- 研判提示：顾客/知识 bundle 中是否有"计划外冒出来的机会"？

### 2. 不协调（kp-i04-01 · 内部）
- 现实与假设、或现实与努力之间的不协调。
- 特征词：投入很多却收效甚微、用户行为与分析预期矛盾、成本高但价值感知低。
- 研判提示：知识侧"四维度薄弱项"或顾客侧"价值错位"是否暴露不协调？

### 3. 流程需要（kp-i05-01 · 内部）
- 某个环节缺失导致整个流程卡顿，补齐即创新。
- 特征词：缺一环、手工环节、转手损耗、等待瓶颈。
- 研判提示：新能力清单中的"补强方向"多落入此源。

### 4. 产业/市场结构变化（kp-i06-01 · 内部）
- 产业突然成熟、集中度变化、渠道重构。
- 特征词：新渠道崛起、中间商消失、平台化、上下游整合。
- 研判提示：顾客侧"竞争替代(M6)"是否由结构变化驱动？

### 5. 人口统计（kp-i07-01 · 外部）
- 年龄/收入/教育/地理/家庭结构变化。
- 特征词：银发、Z世代、城市新中产、县域、单身家庭。
- 研判提示：非顾客组(M5)是否对应某人口结构变化？

### 6. 认知/观念变化（kp-i08-01 · 外部）
- 人们对同一事实的"看法"改变（事实未变，意义变了）。
- 特征词：健康意识、国潮、松弛感、反内卷、可持续。
- 研判提示：顾客"价值定义(M4-3)"是否反映观念迁移？

### 7. 新知识（kp-i09-01 · 外部 · **重点**）
- 基于知识的创新——科学、技术、社会/管理知识的新突破。
- 特征词：新科学发现、新工具/AI、新管理方法、跨学科融合、社会创新。
- **研判提示（本技能重点）**：当机会由"新出现的知识/技术/认知"驱动时，显式命中 kp-i09-01，并 cross-link kp-07-04（知识是差异化根源）——企业的**独特知识 × 外部新知识** = 新知识创新机会。
- **难度最高**：提前期最长、需知识融合、窗口期有限（kp-i09-02）。社会创新同样重要甚至更重要。
- **产出**：单列"新知识创新机会假设卡"，供用户判断要不要把"新知识创新"加进课程（人拍板，AI 只给判断）。

## 二、归因方法（在 ⑥ 步使用）
1. 取 ④新机会清单每条。
2. 用上述"特征词"做粗匹配，允许命中多源（机会常跨源）。
3. 若匹配到"新知识"特征词 → 必标 kp-i09-01，并写清"驱动的新知识 + 与现有知识资产距离"。
4. 输出"创新源命中表"：机会 | 命中源(KP) | 说明。
5. 结论性质表述一律标"需人工复核 / 假设·待验证"。

## 三、与双向反馈的关系
- ② 知识→市场反馈 产出的"错失或低估的市场机会"，往往对应 人口/认知/结构 等外部源——新知识源则更多来自 ③ 市场→知识反馈 揭示的"待补知识"与现有独特知识的融合。
- 因此"新知识创新机会"通常出现在：知识侧独特知识 × 外部新知识趋势 的交汇处。

## 四、外部市场情报如何增强三外部源（本技能第三维）
引入 `market_context`（见 `market_intelligence.md`）后，人口/认知/结构三外部源的研判质量显著提升，不再依赖访谈中偶然提到的抖音/无糖等碎片：
- **人口(kp-i07-01)**：market_context 的"人口与认知变化"维度直接供给银发/Z世代/县域/单身家庭等结构数据，与内部独特知识交叉 → 细分人群机会。
- **认知(kp-i08-01)**：market_context 的"消费变迁/趋势"供给健康意识/国潮/松弛感/情绪价值等观念迁移，喂出更稳的"认知变化"归因。
- **产业结构(kp-i06-01)**：market_context 的"渠道变化/竞争结构"供给零食量贩/折扣店/电商/白牌冲击等重构事实，让"结构变化"归因有公开依据。
- 研判时：凡命中三外部源，优先回溯 market_context 条目 source 作为佐证，置信度按"市场公开信息"基准（中/低·需核实）。
