# 市场情报上下文（Market Context）· 采集与结构

> 配合 `SKILL.md` ①.5 与 ④⑤。本文件定义「外部市场情报」这一**第三维输入**的获取方式、数据结构与诚信规则。它让机会综合不再只吃企业自己的顾客/知识 bundle，而能把对【休闲零食/解馋充饥】等整个行业的更广认知带入研判。

## 一、两种获取方式（任选其一，首选 A）

### 方式 A：用户提供市场简报（最干净、可溯源、不编造）
- 用户粘贴行业报告 / 券商研报 / 咨询公司简报 / 竞品研究报告，或指向 `market_context.md` / `market_context.json`。
- 技能直接解析使用，**每条结论天然带出处**（报告名/机构/日期），置信度可标中。
- 适合：企业已有行业研究积累、或希望 AI 严格基于给定材料。

### 方式 B：AI 主动检索（增强）
- 若用户未提供，技能调用 WebSearch，针对「{事业/品类} + 休闲零食/解馋充饥 + 市场趋势 / 渠道变化 / 消费者变迁 / 竞争格局 / 人口与认知变化」做定向检索。
- 把检索结果结构化沉淀为 `market_context`：每条带来源 URL / 报告名 + 检索日期 + 置信度（一律中/低 · 需核实）。
- 适合：企业自身市场视野有限、希望 AI 补上"广阔市场"那一环（即老师反馈第 3 条场景）。
- **诚信约束**：只记录检索到的公开信息，禁止脑补；若检索结果稀少或矛盾，标「外部情报不足·建议补充行业简报」。

### 缺省
- 用户未提供 且 无检索能力/未授权检索 → 跳过 ④⑤ 外部部分，退回纯双向，并在产出物显著标注「未引入外部市场情报·机会可能偏窄」。

## 二、数据结构（market_context）

无论 A/B，统一为以下结构（markdown 或 json 均可，字段对齐）：

```
market_context:
  meta:
    category: 行业/品类（如 休闲零食·饼干 / 解馋充饥）
    sourced_from: 用户简报 / WebSearch
    retrieved_at: 日期
    confidence_default: 中 | 低
  items:                         # 市场情报条目列表
    - id: M-01
      dimension: 趋势 | 渠道变化 | 消费变迁 | 竞争结构 | 人口与认知变化
      claim: 一句话市场事实/判断（如 "无糖/低糖健康零食增速显著高于传统饼干"）
      source: 来源 URL / 报告名（必填，禁止为空）
      source_type: 市场公开信息
      confidence: 中 | 低
      note: 可选补充
```

### dimension 取值与机会综合用法
| dimension | 含义 | 在 ④⑤ 中的用法 |
|---|---|---|
| 趋势 | 品类/技术/健康化等方向性变化 | × 内部独特知识 → 市场空白机会 |
| 渠道变化 | 零食量贩/折扣店/电商/内容种草等新渠道崛起 | × 内部柔性/关系能力 → 渠道型机会 |
| 消费变迁 | 购买场景、解馋/充饥/情绪价值等用途迁移 | × 内部产品知识 → 用途扩展机会 |
| 竞争结构 | 头部集中、代工崛起、白牌冲击等 | − 内部能力 → 结构性能力差距 |
| 人口与认知变化 | 银发/Z世代/县域/健康意识/国潮等 | × 内部独特知识 → 细分人群机会（同时喂 ⑦ 创新源 人口/认知） |

## 三、WebSearch 检索建议（方式 B）

针对「休闲零食/解馋充饥」类事业，建议检索组合（一次 5 组以内）：
1. `{品类} 市场规模 增速 趋势 2025`
2. `{品类} 渠道 零食量贩 折扣店 电商 内容种草`
3. `{品类} 消费者 银发 健康 无糖 Z世代 县域`
4. `{品类} 竞争格局 头部品牌 白牌 代工 OEM`
5. `{品类} 创新 新品 案例 国潮`

检索结果去重、按 dimension 归类，每条保留来源 URL；矛盾信息并存并标「待核实」。

## 四、诚信与红线（不可违背）

- **可溯源**：每条 market_context 条目 `source` 必填；标 `市场公开信息` 的机会/能力须回溯到该 source，不得与企业原话(src)混写。
- **不编造**：WebSearch 未检索到的结论不得写入；检索稀疏时降级标注，不臆造行业数字/份额。
- **置信度诚实**：市场公开信息默认中/低，且产出的机会/能力一律「需核实」；不得因"听起来合理"升为高。
- **来源类型分层**：在机会综合画布中，来源类型列必须区分 `企业原话` / `市场公开信息` / `AI推演`，外部条目不得伪装成企业原话。

## 五、与家族衔接

- 上游：用户简报 或 本技能 WebSearch。
- 消费方：`ddd-opportunity-synthesis` ①.5 读取、④⑤ 融合。
- 下游：外部印证/差距表可回流 `ddd-knowledge-survey`，提示企业"补采市场级知识"以缩小内部 vs 市场的视野差。
