# 机会综合画布 · 字段定义（Output Schema）

> 配合 `assets/opportunity_matrix_template.html`。本技能产出三张清单 + 一张矩阵 + 一张外部印证/差距表，全部字段定义如下。所有条目须可回溯到双 bundle 原话（src）或市场情报出处（source），并打**来源类型**标签。

## 一、新机会清单（⑥ 聚合 ② + ②'）
| 字段 | 含义 | 填写规则 |
|---|---|---|
| 机会ID | 稳定主键，如 O-01 | 顺序编号 |
| 机会描述 | 错失/低估的市场机会 或 市场空白机会 | 一句可执行陈述；双向措辞锁定"错失或低估"，外部措辞标"市场空白" |
| 来源维度 | 内部双向 / 外部市场空白 / 交叉验证 | 必填；区分"来自企业自己"还是"来自广阔市场" |
| 来源类型 | 企业原话 / 市场公开信息 / AI推演 | 必填；对应数据信任分层 |
| 来源溯源 | 知识cell_id/顾客cell_id + 原话 src，**或** 市场出处(URL/报告名) | 至少 1 条；外部条目写 market_context source，非 cell_id |
| 置信度 | 高/中/低 | 高=双源一致；中=部分/市场印证；低=单条/外部未核实 |
| 状态 | 已验证 / 假设·待验证 / 证据不足·建议补访 | 默认"假设·待验证"；外部条目"需核实" |
| 初步命中创新源 | KP（如 kp-i07-01） | 可选，⑧步再精修 |

## 二、新能力清单（⑦ 聚合 ③ + ③'）
| 字段 | 含义 | 填写规则 |
|---|---|---|
| 能力ID | 稳定主键，如 C-01 | 顺序编号 |
| 能力缺口 | 企业需补充的新知识/能力 | 一句陈述；对称知识侧 1.2 知识短板 |
| 来源维度 | 内部缺口 / 市场要求差距 | 必填；区分内部个案缺口 vs 全行业结构性差距 |
| 来源类型 | 企业原话 / 市场公开信息 / AI推演 | 必填 |
| 命中证据 | 顾客cell + 原话，**或** 市场出处 | 至少 1 条 |
| 建议知识补强方向 | 该补哪类知识 | 可 cross-link kp-07-08（表达）/ kp-07-04（三源） |
| 置信度 | 高/中/低 | 同上 |

## 三、创新源命中表（⑧）
| 字段 | 含义 |
|---|---|
| 机会ID | 关联 一 |
| 命中源 | KP（含重点 kp-i09-01） |
| 说明 | 为何命中该源；新知识源须写"驱动的新知识 + 与现有知识资产距离" |

## 四、机会×能力矩阵（⑨）
- 行 = 新机会清单（O-01…）；列 = 新能力清单（C-01…，含市场要求差距项）。
- 单元格 = { 是否需该能力支撑该机会(是/否) | 支撑强度(高/中/低) | 备注 }。
- 用途：一眼看出"哪些机会已被现有/待补能力覆盖，哪些机会还缺能力支撑"。

## 五、外部印证 / 差距表（⑨ 新增）
| 字段 | 含义 |
|---|---|
| 类型 | 印证 / 差距 / 冲突 |
| 关联对象 | 机会ID 或 能力ID，或内部判断描述 |
| 市场情报依据 | market_context 条目 source（URL/报告名） |
| 说明 | 印证→置信度上调；差距→能力缺口·市场级；冲突→需复核·数据冲突 |

## 六、[内部]方法论说明（Word 交付物）
框架来源（kp-07-09 / kp-i09-01）、三向融合逻辑、数据诚信边界（双 bundle 原话 + 市场出处消费、不编造）、来源类型分层、AI 角色边界、与上下游衔接。不进入客户产物。

## 七、外部市场情报来源索引（来源地址留存 · 报告末尾附录）
> 满足"外部信息的来源地址在报告最后保留"的要求：把本报告消费的全部 `market_context` 条目出处集中列在末尾，便于核查与复核。

| 字段 | 含义 | 填写规则 |
|---|---|---|
| 编号 | market_context 条目 id，如 M-01 | 顺序 |
| 维度 | 趋势 / 渠道变化 / 消费变迁 / 竞争结构 / 人口与认知变化 | 与 market_context 一致 |
| 情报摘要 | 该条市场情报的 claim | 精简一句 |
| 来源地址 | 公开报告名 / 检索 URL | **必填**；"同上"须展开为前一条真实出处；无来源不得写 |
| 置信度 | 中 / 低 | 沿用 market_context |

- 报告渲染位置：HTML 模板「七、外部市场情报来源索引」置于「六、新知识卡」之后、footer 之前。
- 未引入外部市场情报（无 market_context）时，该表仅一行「未引入外部市场情报·机会可能偏窄」，不得留空或虚构。
- 同步进入 `delivery_bundle.json` 的 `source_index` 数组（机器可读，供下游/复核）。
