# 德鲁克知识点 · 预编译 KP 摘要（分析视角 · 离线底座）

> 来源：`~/DruckerWiki`（《为成果而管理》kp- / 《管理的实践》kp-g）。本文件是关键 KP 的**预编译摘要 + 分析时的应用指引**，供本技能离线使用，无需联网检索。需要原文时再去知识库读对应 KP 全文。
> 视角：这不是「设计问卷」用的 KP，而是「分析调研结果」时要用到的 KP——每条都标注「分析时怎么用」。

## 一、总纲：企业目的在外部

- **kp-01-01 企业的目的是在外部产生成果**：企业内部只有成本核心，成果由外部顾客决定。
  - **分析时怎么用**：分析结果的归属永远是「外部现实/成果」，不是「内部总结」。第一动作是问"这些原话指向哪个外部成果？"
- **kp-06-01 / kp-g05-01 顾客即企业·企业的目的是创造顾客**：是顾客付钱把资源变财富。
  - **分析时怎么用**：每条洞察都要回答"我们在为谁创造价值"。

## 二、市场营销八大现实（kp-06-03）— 分析的 reality check 总纲

八条（分析时逐条拿原话对照）：
1. 内部人不懂顾客 → 我们的结论里有多少是"我们以为"而非"顾客说"？
2. 顾客因满足感而买，不是因产品 → 原话里顾客买的"满足感/最终用途"是什么？
3. 直接对手不足以界定竞争 → 顾客亲口提到的替代满足感有哪些？
4. 制造商看重的质量顾客未必在意 → 我们引以为傲的质量，顾客原话里有提吗？
5. 没有产品缺之不可 → 顾客"没有我们也行"的替代成本多低？
6. 通常不知顾客是谁，须去找 → 我们之前假设的画像，被原话打脸了吗？
7. 顾客是做决定的人而非付钱人 → 决策链里谁有否决权？
8. 无识别顾客者应以市场/最终用途为分析起点 → 分析起点应是"最终用途"而非"我们的产品线"。

> 金句：「真懂顾客的唯有一人，即顾客自己。」→ 全程"用原话对照内部假设"，拒绝内部结论。

## 三、内部视角盲区（kp-06-02）

企业内部人看不清自己的独特知识，也看不清顾客为何付钱；许多"分析"其实只是系统化自证。
- **分析时怎么用**：强制把"企业预填的我们以为"摆在分析结果开头，逐条与原话对撞，产出"认知偏差清单"。

## 四、顾客三问（kp-g06-02）

- 谁是我们真正的顾客？谁又是潜在顾客（非顾客）？
- 顾客购买的是什么？
- 顾客心中的价值是什么？
- **分析时怎么用**：这是画像与价值锚点的重建骨架。三问答完，调研的"顾客是谁/买什么/价值"才成立。

## 五、顾客是做决定的人（kp-06-05）— 决策链 / 渠道即顾客

顾客=做出购买决定的人，至少分最终买家与分销渠道两类，都有否决权。决策者常≠使用者（送礼：买的人 vs 用的人）。
- **分析时怎么用**：画像必须含"决策链角色"——谁决定、谁影响、渠道即顾客。漏掉否决权者=分析失真。

## 六、满足感 + 最终用途（kp-06-04 / kp-06-06）— JTBD

顾客买的不是产品而是满足感；竞争边界由需求定义。三维度：顾客/市场/最终用途。
- **分析时怎么用**：价值分层穿透"表层产品→中层方案→深层情感+最终用途"。原话"买了打孔机"→ 真实要的是"墙上的孔"。

## 七、顾客心中的价值（kp-g06-03）— 须直接探询

「在顾客心目中价值是什么」最难，价值≠低价，管理层不应臆测，须系统化直接向顾客探询。
- **分析时怎么用**：价值锚点必须来自顾客原话。分"付款前看重 vs 体验后看重"并标错位（购后价值才是真价值）。

## 八、非顾客（kp-06-07）— 增长金矿【红线：必含】

最大的增长常藏在不买的人那里。非顾客=已经或可能在市场里却不买的人。三类：①有需求未接触 ②接触未成交 ③曾流失。不买常因渠道/场景/认知错配，而非没需求。
- **分析时怎么用**：单独把非顾客三类拎出，问"为什么不买？是没需求还是错配？"产出"非顾客机会清单"。

## 九、产品聚合 / 非竞争对手（kp-06-09 / kp-06-10）

顾客按"满足感"把产品聚合成完形，而非按制造商产品线。要找"我们是谁的非竞争对手"（哪些机会被误认为不属于本行业）。
- **分析时怎么用**：竞争分析按满足感聚合，标"②③交界处"——顾客有需求、各方都没满足好的战略空白。

## 十、看懂顾客（kp-06-11）

尊重顾客"看似非理性"的行为，探寻使其行为变得理性的现实处境——这是从市场视角看企业最快的方法。
- **分析时怎么用**：扫描原话中"从制造商逻辑看不合理"的行为（如宁付高价选交期短的），推其背后现实处境，生成"看懂顾客两问"草稿：行为 → 推测处境 → 原话。**仅当草稿，洞察归人。**

## 十一、目标管理（kp-g11-01）— 验收口径

把配额（如每类 10 份）设为可量化、可验收目标。
- **分析时怎么用**：置信度判定参考样本覆盖——某结论是否有足够多顾客原话支撑（如"7/10 非顾客均提及"→ 高置信）。
