# 分析 Playbook · 7 步流水线 + KP 映射 + 认知偏差模板

> 本文件把 SKILL.md 的 7 步流程展开为可操作的执行手册。每步给出：目标、操作、输出、对应 KP、常见错。预编译 KP 见 `drucker_kb_precompiled.md`。

## 总览
```
① 立场校准(八大现实) → ② 三问重建 → ③ 非顾客归因 → ④ 价值分层
→ ⑤ 看懂顾客两问 → ⑥ 竞争聚合 → ⑦ 画布+报告组装(HTML)
```

---

## ① 立场校准 — 八大现实对照
- **目标**：先剥离内部假设，建立"外部现实"基准。
- **操作**：
  1. 若用户提供了企业预填"我们以为"（产品定位/目标顾客/自认优势），原样列出。
  2. 逐条拿八大现实（见 precompiled 第二节）对照原话，标注"吻合 / 冲突 / 未触及"。
  3. 输出**认知偏差清单**：冲突项即"内部假设被外部打脸"的高价值信号。
- **输出**：认知偏差清单（含每条冲突的原话证据）。
- **KP**：kp-01-01 / kp-06-03 / kp-06-02。
- **常见错**：跳过此步直接归纳 → 结论沦为"内部自证"。

## ② 三问重建 — 谁 / 买什么 / 价值
- **目标**：重建顾客画像与价值锚点的地基。
- **操作**：
  1. 从原话抽"谁"：现实顾客 vs 非顾客；买家 vs 渠道；使用者 vs 决策者。
  2. 抽"买什么"：表层产品名 → 中层任务（JTBD）→ 深层最终用途。
  3. 抽"价值"：顾客原话里的价值定义（不问企业）。
- **输出**：三问初稿（后续在 ④ ⑤ 深化）。
- **KP**：kp-g06-02 / kp-06-05 / kp-06-04。
- **常见错**：把"使用者"当"决策者"，漏掉渠道的否决权。

## ③ 非顾客归因 — 三类 + 流失原因
- **目标**：挖出增长金矿（红线必含）。
- **操作**：
  1. 非顾客原话归入三类：从未接触 / 接触未成交 / 曾流失。
  2. 每类提炼流失原因 Top（渠道错配 / 场景错配 / 认知错配 / 真无需求）。
  3. 标注每类样本量与代表原话。
- **输出**：非顾客机会清单（三类 × 原因 Top × 原话）。
- **KP**：kp-06-07。
- **常见错**：只分析已购买者，把非顾客当"不重要"省略。

## ④ 价值分层 — 表层/中层/深层 + 购前购后
- **目标**：穿透到最终用途，并暴露价值错位。
- **操作**：
  1. 把"买什么"映射到三层：表层产品 → 中层方案 → 深层情感+最终用途。
  2. 分列"付款前看重因素"与"体验后看重因素"。
  3. 标错位：购前购后差异大处，即"企业误判的价值点"。
- **输出**：价值锚点分层表（含购前购后对比与错位诊断）。
- **KP**：kp-06-04 / kp-06-06 / kp-g06-03。
- **常见错**：不分层、不标错位，价值分析停在"性价比高"层面。

## ⑤ 看懂顾客两问 — 非理性行为 → 现实处境
- **目标**：产出分析高潮——"从市场视角看企业"的草稿。
- **操作**：
  1. 扫描原话中"从制造商逻辑看不合理"的行为（如宁付高价选交期短、为送礼买课）。
  2. 对每例推"使其行为变得理性的现实处境"。
  3. 格式：行为 → 推测现实处境 → 支撑原话。**全部标"草稿·假设·待验证"**。
- **输出**：看懂顾客两问草稿（3–5 条）。
- **KP**：kp-06-11。
- **常见错**：把推断当结论写出来（违反红线②）。

## ⑥ 竞争聚合 — 满足感视角 + ②③空白
- **目标**：跳出"直接对手"，找战略空白。
- **操作**：
  1. 从原话抽顾客亲口提到的替代满足感，归入直接/间接/非竞争对手。
  2. 按"满足感"而非"产品线"聚合（如"下午解馋"把奶茶与饼干归同满足感域）。
  3. 标"②③交界处"：顾客有需求 + 各方都没满足好的空白。
- **输出**：竞争全景（三类）+ 战略空白清单。
- **KP**：kp-06-09 / kp-06-10。
- **常见错**：只列直接对手，按产品线而非满足感聚合。

## ⑦ 画布 + 报告组装（HTML）
- **目标**：把以上全部落成可交付物。
- **操作**：
  1. 用 `assets/customer_canvas_template.html`：每格填 结论 / 原话支撑 / 置信度 / 状态（字段规则见 `canvas_schema.md`）。
  2. 用 `assets/insight_report_template.html`：填入看懂顾客两问 + 非顾客机会 + 竞争空白 + 行动假设卡（叙事部分）。
  3. 平台沉淀（检查项）：检测协作工具，按 `references/collab_delivery.md` 推画布为多维表格、推报告为在线协作文档（在线文档以叙事为主，可按适配器能力以图片嵌入或链接）。
- **输出**：顾客分析画布（HTML）+ 洞察报告（HTML）。
- **KP**：顾客三问 / 知识三源（本技能仅承接，不含知识画布）。
- **常见错**：格子无原话、置信度不标、把假设当定论、行动假设卡缺失。
