# 画布 Schema · 顾客分析画布字段定义 + 填写规则

> 本技能**只产出顾客分析画布**（知识分析画布已按用户要求移除，D1 独特知识仅在 3.4 格轻量列出候选，不展开三源验证/四维度诊断——那是思路③）。HTML 模板见 `assets/customer_canvas_template.html`。

## 画布定位：三列对应「顾客三问」

| 列 | 对应问题 | 含义 |
|---|---|---|
| 列1 顾客是谁（Who） | 谁是我们的顾客？ | 画像 + 市场渠道传播 |
| 列2 买的是什么（What） | 顾客购买的是什么？ | 表层产品 → 中层方案 → 深层情感 + 最终用途 |
| 列3 认为的价值（Value） | 顾客心中的价值是什么？ | 购前看重 + 购后看重 + D 类独特价值 |

## 格子清单（共 11 格）

### 列1：顾客是谁（Who）
- **1.1 现实顾客画像**：触达渠道、信任来源、决策链角色（谁决定/谁影响/渠道即顾客）
- **1.2 非顾客画像（三类）**：从未接触 / 接触未成交 / 曾流失 + 各类型流失原因 Top3
- **1.3 认知偏差点**：企业"我们以为" vs 顾客"实际说"（八大现实对照结果）

### 列2：买的是什么（What）
- **2.1 表层产品**：顾客口中的产品/品类名
- **2.2 中层方案**：解决的具体问题 / 任务（JTBD）
- **2.3 深层情感 + 最终用途**：为什么这件事对他重要（钻头 vs 孔）
- **2.4 购前 vs 购后对比**：错位处标红

### 列3：认为的价值（Value）
- **3.1 购前价值锚点**：付款前看重因素 + 权重
- **3.2 购后价值锚点**：体验后看重因素
- **3.3 错位诊断**：购前购后差异意味着什么（企业误判点）
- **3.4 D1 独特价值候选**：顾客原话里的"别家做不到"（轻量列出，标"待思路③深化"）

## 每格四字段（必填规则）

| 字段 | 规则 |
|---|---|
| **结论** | 一句话，中性陈述，不替企业下判断 |
| **原话支撑** | `{quote}` + 出处（场次/题号/时间戳），≥1 条；无原话则标"证据不足·建议补访" |
| **置信度** | 高 / 中 / 低。判定：高=多顾客一致提及(如≥7/10)；中=部分提及；低=单条或矛盾 |
| **状态** | 已验证 / 假设·待验证 / 证据不足·建议补访 |

## 原话挂载规则
- 格式：`「原话文本」（场次S3·M5-12·00:42）`
- 一条结论可挂多条原话（共识候选）；矛盾原话并存并标"需人工探讨"。
- 禁止把概括/转述当原话。

## 与 ddd-customer-survey 的衔接
- `ddd-customer-survey` 的 `analysis_schema.md` 已定义"题项→画布字段+原话溯源"映射。
- 本 schema 的 11 格直接消费该映射：例如 M3-5/6 → 3.1/3.2 价值锚点；M5-11/12/13 → 1.2 非顾客；M4-7/8/9 → 2.2/2.3 价值与用途。
- 若上游产出已结构化（题—答—原话），本技能跳过轻量映射，直接进入 ②③④ 升维。
