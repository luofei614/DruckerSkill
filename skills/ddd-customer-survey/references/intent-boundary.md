# 能力边界详解 · 输入参数 · 平台检测补充

> 本文件承载 `SKILL.md` 下放的细节层（资源边界原则：SKILL.md 只留路由/骨架/契约/红线，细节在此）。

## 一、能力句（Capability Sentence）

> 把彼得·德鲁克的顾客分析方法论，固化为「输入事业/产品 + 调研目的 → 输出标准化调研设计包」的可复用能力，使每次调研设计都自动带上非顾客视角、防引导红线与德鲁克知识点溯源，且客户产物纯净可用。

## 二、近邻排除项（Exclusions，详解）

| 排除项 | 说明 | 交由谁 |
|---|---|---|
| 问卷数据采集与统计分析 | 本技能产出「设计」，不收数据、不做聚类 | 下游 C4 聚类 / 数据技能 |
| 替企业/顾客下结论 | AI 只提取组织，价值与结论由人定 | 企业决策者（人工复核） |
| 实际拨打/执行访谈 | 只产出提纲，不代跑 | 调研员/销售 |
| 纯问卷工具排版 | 问卷星等仅导出可导入格式 | 用户手动导入平台 |
| 覆盖知识分析坊 | M7 D1 仅采集交接，不向内深挖 | 知识分析工作坊 |
| 营销战略咨询 | 不做战略建议，只做调研设计 | 咨询/管理层 |

## 三、完整输入参数表

**必填参数**（缺失须先追问，一次 ≤5 项，按优先级）

| 参数 | 含义 | 示例 |
|---|---|---|
| `business_context` | 事业/产品描述（越具体越好，或一页纸经营构想） | 「道家线上课：面向都市白领的压力管理课」 |
| `research_purpose` | 调研目的（四选一） | 上线前需求探询 / 上线后复购·NPS / 非顾客增长挖掘 / 知识发现 |
| `channels` | 触达渠道 | 企微 / 在线问卷 / 电话访谈 / B站·视频号动态 |
| `sample_plan` | 样本量与分群配额 | 「每类 10 份」 |

**建议参数**（缺省由 skill 反推并标注「假设」）

| 参数 | 含义 |
|---|---|
| `customer_assumption` | 目标顾客假设画像 |
| `include_non_customer` | 是否含非顾客分支（默认 **true**，德鲁克硬约束） |
| `competitors` | 已知竞争/替代满足感 |
| `time_window` | 成果锚定时间窗（结论最晚何时要） |
| `drucker_focus` | 侧重框架（八现实/三问/四所/非顾客/价值/独特知识） |
| `output_targets` | 需要哪些产物（默认全产：方案+问卷+提纲+schema） |

## 四、平台检测补充（配合 references/platform_export.md）

- 检测时机：仅在步骤 ⑦ 进行，**不假设**始终可用——读取当下 `<connector-status>` 的 `connected` 项。
- 优先级提示：多维表格类（飞书/钉钉/企微/金数据）适合「设计→采集→分析」闭环；问卷平台（腾讯问卷）适合规模化投放。
- 问卷星特殊处理：无官方 MCP connector，输出「可粘贴导入」题目清单（每题一行，标题型）+ 手动导入步骤，不谎称已连接。
- 红线贯穿：无论落到哪个平台，防引导校验规则不变；开放题不得被平台强行改成封闭选项。
