## 2. 命名前缀（硬区分四书）

| 书 | 前缀 | 示例 |
|---|---|---|
| 为成果而管理 | `kp-` | kp-06-02-顾客三问 |
| 管理的实践 | `kp-g` | kp-g06-02-谁是顾客 |

`id` 带各自前缀，跨书互链一律用 `see_also_external`（`书名#第N章(主题)`）或正文 `[[完整文件名|显示名]]`。

## 3. KP 文件 frontmatter 字段（检索关键）

| 字段 | 含义 | 检索用途 |
|---|---|---|
| `id` | 机器键（带前缀） | 本书内关联 |
| `title` | 中文标题 | 高权重匹配 |
| `aliases` | 同义词数组 | 高权重匹配（如「外部成果」「成果在外部」） |
| `tags` | 受控标签 | 中权重匹配 |
| `chapter` | 第X章 主题 | 章号定向召回 |
| `summary` | 一句话摘要 | 中权重匹配 |
| `symptoms` | 企业痛点词 | 痛点召回 |
| `scenarios` | 场景词（S/PS/ES/IN） | 场景召回 |
| `frameworks` | 工作坊框架名 | 框架召回 |
| `source_book` | 书名 | 书名定向召回 |
| `coverage` | 🟢库内全覆盖 / 🟡部分 / 🔴外部依赖 | 命中🔴须提示另查 |
| `related` | 本书关联 id | 串联扩展 |
| `xu` | 是否含徐井宏解读 | 书A 专属 |
| `status` | draft / verified | 置信参考 |

## 4. KP 正文标准段（答案素材）

`## 检索骨架`（原话观点 + 德鲁克的提问）→ `## 概念关系` → `## 检索导言` → `## 核心定义` → `## 关键论点（德鲁克原意）` → `## 原书原文摘录` → `## 企业应用` → `## 典型症状·红旗信号` → `## 常见误区` → `## 自检·引导问题` → `## 示例企业问题` → `## See Also`。

答案生成优先取：原话观点 / 原书原文摘录（逐字）、关键论点、核心定义、概念关系、企业应用、自检问题。

## 5. 检索入口优先级

1. `index.md` §2 跨书痛点地图（痛点 → 首选 KP）
2. `concepts/` 跨书概念合订（概念 → 四书怎么讲）
3. 各书 `<书名>.md` 痛点/场景/标签/层级树索引
4. 直接遍历 `kp/` 全文（脚本精排）

## 6. 来源纪律

- 德鲁克原话标 `《书名》第X章（raw/书名.md Lxxx）`。
- `> 💡 当代注解（AI 补充，非德鲁克原意）` 为 AI 对年代语境说明，绝不冒充原文。
- 徐井宏解读仅书A 部分 KP 含（`xu:true`），引用须注明「徐井宏说/讲」。
