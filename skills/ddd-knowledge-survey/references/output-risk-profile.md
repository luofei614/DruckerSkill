# 客户产物输出风险画像 + reviewer 检查项

> 知识分析设计包（docx）交付前，自检以下 6 类风险。每类给出「表现 / 后果 / 检查项」。

## 风险 1：把资源当知识
- **表现**：画布结论写"我们有原纸渠道优势/厂房大/资金足"。
- **后果**：混淆 kp-07-02/03，知识画布污染。
- **检查项**：凡"可购买/可替代"项，必须标「资源」并移出知识结论。

## 风险 2：三源缺一
- **表现**：只做了 A 类（跟别人比），漏 B/C 或漏 A2 反向缺口。
- **后果**：自我欺骗，违反 kp-07-04。
- **检查项**：A1+A2、B1、C1 四类原问题必须全部出现。

## 风险 3：形容词伪知识
- **表现**："我们质量好/服务好/经验丰富"进画布。
- **后果**：不可验证、不可传递，违反 kp-07-08。
- **检查项**：每条知识候选须能改写为"在 XX 领域，能做好 XX 事"。

## 风险 4：改写了原问题/原话
- **表现**：AI 把"什么事我们干不好而别人干成"优化成引导式问法；记录做了二次总结。
- **后果**：丢原话价值，违反 kp-07-05。
- **检查项**：探询问与手册原问题逐字一致；记录为原话。

## 风险 5：缺易腐/更新提示
- **表现**：设计包无半年回顾约定。
- **后果**：一次性盘点，知识很快过时，违反 kp-07-06。
- **检查项**：设计包含"知识更新机制"段落。

## 风险 6：内部字样泄露
- **表现**：客户产物出现 `kp-07-xx` / 德鲁克 / 方法论 / 防引导。
- **后果**：不专业、暴露内部框架。
- **检查项**：交付前字符串扫描，命中即返工。

## Human Review 要点（reviewer 须确认）
- [ ] 三源四类原问题齐全且为原表达
- [ ] 资源与知识已区分
- [ ] 知识候选均为动词+名词可表达
- [ ] 含易腐/更新机制提示
- [ ] 客户产物零内部字样
- [ ] C 类已尝试对接 D1（或标注待探询）
