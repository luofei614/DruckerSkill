# 平台检测与探询表沉淀指引

> 镜像 `ddd-customer-survey` 的 platform_export。知识探询表（A/B/C 类 + 分工安排）可沉淀到协作文档/多维表格，便于原话记录与下游消费。

## 一、支持平台（检测 connector 状态）
- 飞书多维表格 / 飞书文档
- 钉钉 AI 表格 / 钉钉文档
- 企业微信 AI 表格
- 问卷星（仅导出可导入格式）

## 二、沉淀内容
1. **A/B/C 类探询收集表**（附件2 结构）：序号 / 探询对象 / 填写人 / 原话。
2. **分工安排表**（附件1 结构）：分析维度 / 核心问题 / 负责人 / 截止时间。
3. **知识画布空框** + **诊断 schema 空框**（供下游填写）。

## 三、沉淀流程
1. 运行时检测 connector 状态。
2. **询问用户**是否沉淀（不默认外发）。
3. 生成可导入格式（如飞书多维表格字段映射 / 问卷星 CSV）。
4. 提示：原话记录须保留"原始、不改写"，下游 `ddd-knowledge-insight` 直接读取。

## 四、不沉淀的情形
- 用户未授权；连接器未连接；涉及敏感客户原话且未脱敏。
- 此时仅交付本地 docx，标注"待用户授权后沉淀"。
