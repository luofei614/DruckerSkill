# 分权与有计划放弃 (Decentralization & Planned Abandonment)

> **类型**: concept | **创建时间**: 2026-07-24 | **来源**: 跨书合订（管理的实践 / 为成果而管理 / 创新与企业家精神 / 卓有成效的管理者）
> 跨书合订页 · 把四书中「分权」与「有计划放弃」两个相邻纪律一处看全，并双向链回各 KP。

## 摘要
「分权」与「有计划放弃」是德鲁克管理学中一对**互补的"做减法"纪律**：分权是**组织层面**把决策权下放到接触现实的现场（以联邦分权制为典型），让正确的人就近决策；有计划放弃是**资源层面**主动、定期地割舍昨天的生计来源与陪跑者，把资源腾给未来机会。二者共同反对「中央集权 + 什么都舍不得丢」的僵化。分权在《管理的实践》被系统奠基，有计划放弃在《为成果而管理》被确立为资源配置第一原则，并贯穿《卓有成效的管理者》的「抛弃过去」与《创新与企业家精神》的「创新纪律」。

## 整合对比
- **共同内核**：两者都是**系统性"做减法"的管理纪律**——分权是权力下放（让决策贴近现场），有计划放弃是资源割舍（让资源流向机会）；二者都反对「总部集权 + 对昨日包袱恋恋不舍」。
- **互补关系**：分权（结构）让正确的人在现场做决策；有计划放弃（节奏）保证被分权者**定期清理昨日包袱**，不被历史包袱拖垮。德鲁克在《管理的实践》把分权作为组织原则，在《为成果而管理》把放弃作为资源配置第一原则——一纵一横，构成「活的有机体」。
- **⚠️ 张力 / 常见误用**：
  1. **分权若没有"有计划放弃"配套**，会变成「诸侯各自守成」——各单位守着存量、不愿割舍，最终退化为职能型筒仓（见 [[kp-g17-03-职能性组织的弱点|职能性组织的弱点]] 与 [[kp-g11-05-靠压力进行管理|靠压力进行管理]]）。
  2. **放弃若没有分权授权**，由总部替各单元做「放弃」决策会脱离一线现实；放弃决策必须交给最了解现场的人。
  3. 二者须**配套落地**：分权单位配套独立核算与「给上司的信」式目标（[[kp-g11-01-目标管理与自我控制|目标管理与自我控制]] · [[kp-14-04-目标管理与责任|目标管理与责任]]），并把放弃释放的资源直接挂钩 Top 机会（[[kp-09-05-资源再配置有效活动|资源再配置]]）。

## 企业应用（合订处方）
1. 用**活动 / 决策 / 关系分析**定结构，优先采用联邦分权制，避免职能型筒仓。→ [[kp-g16-01-结构追随战略|结构追随战略]] · [[kp-g17-04-联邦分权制|联邦分权制]]
2. 设立**定期放弃清单**：每季度审视可放弃的产品 / 客户 / 流程，资源直接转投 Top3 机会。→ [[kp-09-05-资源再配置有效活动|资源再配置]] · [[kp-e05-02-抛弃过去|抛弃过去]]
3. 分权单位配套**独立核算 + 自我控制式目标**，让现场决策者对成果负责。→ [[kp-g11-01-目标管理与自我控制|目标管理与自我控制]] · [[kp-14-04-目标管理与责任|目标管理与责任]]
4. 放弃决策权下放给**最了解现场的人**，总部只定原则与节奏。→ [[kp-e06-04-斯隆的有效决策（通用汽车）|斯隆的分权决策]]
