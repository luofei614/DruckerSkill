# 创新 (Innovation)

> **类型**: concept | **创建时间**: 2026-07-24 | **来源**: 跨书合订（创新与企业家精神 / 管理的实践 / 为成果而管理 / 卓有成效的管理者）
> 跨书合订页 · 把四书中「创新」相关论述一处看全，并双向链回各 KP。

## 摘要
创新在德鲁克体系中不是天才的灵光一现，而是**系统化、有纪律的工作**：始于对「七大创新来源」的机会扫描，目标是创造顾客新价值与取得领导地位，且**现有企业内也能创业**。它在《创新与企业家精神》中被系统展开（来源→原则→策略），在《管理的实践》中被确立为企业两大基本功能之一并纳入目标体系，在《为成果而管理》中被落到「未来在今天买」的资源布局，在《卓有成效的管理者》中则体现为个人层面「抛弃过去、腾出精力做新事」。

## 整合对比
- **共同内核**：创新是**系统化、有纪律的工作**，不是灵感或天才；始于**机会分析**（七大来源）；目的是**创造新顾客价值 / 取得领导地位**；**现有企业内也能创业**；必须落地为具体业务与资源投入。
- **互补视角**：创新书（机会来源 + 原则 + 策略）→ 管理的实践（创新作为企业基本功能 + 目标设定）→ 为成果（把创新落到「今天为明天布局」的资源再配置）→ 卓有成效（个人层面「抛弃过去」腾出创新所需的精力）。
- **⚠️ 张力 / 常见误用**：
  1. 创新书开篇即警告「**创业不等于开新小企业**」（[[kp-i01-02-创业不等于开新小企业|创业≠开新小企业]]）——企业常把「成立新部门 / 收购」当创新，德鲁克指出这是误区；真正的创业是**创造新价值**。
  2. 创新须「始于将过时事业之外」（[[kp-i02-03-创新的纪律与原则|创新的纪律]]），与为成果「**升级而非颠覆**」（[[kp-09-06-升级而非颠覆|升级而非颠覆]]）一致，却与盲目追求「颠覆式创新」的流行叙事相悖——德鲁克更信任在现有事业内的系统化改进。
  3. 服务机构（含企业内部职能）天然缺乏创业动力（[[kp-i14-01-服务机构为何缺乏创业|服务机构为何缺乏创业]]），需用分权与独立核算破局。

## 企业应用（合订处方）
1. 建立**七大来源扫描机制**（意外/不协调/流程需要/结构变化/人口/认知/新知识），用清单定期诊断机会。→ [[kp-i02-02-七大创新来源总览|七大来源]] · [[kp-i02-06-诊断创新机会的方法|诊断方法]]
2. **现有企业内创业**：设独立单位、用不同节奏与考评，避免被现有业务窒息。→ [[kp-i01-04-现有企业内的创业|现有企业内的创业]]
3. 目标体系纳入**创新目标**，平衡各关键领域与时间幅度。→ [[kp-g07-03-创新目标|创新目标]] · [[kp-g07-09-平衡各种目标|平衡各种目标]]
4. **今天为明天布局**：用第二曲线 / 三层业务把资源预投到未来机会。→ [[kp-11-03-第二曲线|第二曲线]] · [[kp-11-04-三层业务|三层业务]] · [[kp-11-06-创新系统化|创新系统化]]
5. **抛弃过去**腾出资源与精力，使创新有可投的「子弹」。→ [[kp-e05-02-抛弃过去|抛弃过去]]
