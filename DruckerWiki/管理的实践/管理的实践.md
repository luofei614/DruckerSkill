## 0. 全书概览

**一句话主线**：管理是企业的器官；企业的目的是创造顾客，而管理层的三大职能——管理企业、管理管理者、管理员工和工作——必须在每个决策中同时兼顾现在与未来，把经济绩效植入组织。

**全书地图（六大板块，全部 ✅ 已摄入）**：
- 概论·管理的本质（第1–3章，10 KP）：管理层是什么 → 三大职责 → 自动化挑战
- 第一部分·管理企业（第4–9章，29 KP）：西尔斯案例 → 企业是什么 → 我们的事业是什么 → 企业的目标 → 今天的决策明天的成果 → 生产的原则
- 第二部分·管理管理者（第10–15章，31 KP）：福特案例 → 目标管理与自我控制 → 管理者必须管理 → 组织的精神 → 首席执行官与董事会 → 培养管理者
- 第三部分·管理的结构（第16–18章，19 KP）：三种分析定结构 → 联邦分权制与职能分权制 → 大小企业与成长
- 第四部分·管理和工作（第19–26章，24 KP）：IBM案例 → 雇佣整个人 → 人事管理反思 → 巅峰绩效组织 → 激励 → 经济层面 → 主管 → 专业人员
